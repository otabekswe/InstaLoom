# InstaLoom logo

- `instaloom-logo.svg` — blue mark with an ink wordmark; light backgrounds.
- `instaloom-logo-white.svg` — white artwork; dark backgrounds.
- `instaloom-logo-mono.svg` — single color (`currentColor`); print or inline use.
- `instaloom-mark.svg` — standalone icon.

All SVGs have transparent backgrounds and editable paths. The wordmark uses outlined Geist; no installed font is needed. Blue: `#2563eb`. Ink: `#0f172a`.

Keep the proportions unchanged. Allow at least one stroke width of clear space. Use the mark alone when the name would be too small to read.
